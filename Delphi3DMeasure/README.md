## Функционал

### Основные возможности:

1. **Загрузка OBJ файлов** - поддержка вершин, нормалей и граней
2. **3D курсор** - отображается на поверхности модели при наведении
3. **Расстановка точек** - клик ЛКМ добавляет точку на поверхность модели
4. **Измерения** - автоматическое соединение точек и расчет расстояний
5. **Масштабирование** - установка точного масштаба по реперным точкам
6. **Экспорт данных** - сохранение измерений в текстовый файл

### Управление:

| Действие | Управление |
|----------|------------|
| Вращение камеры | ЛКМ (левая кнопка мыши) |
| Перемещение камеры | Shift + ЛКМ |
| Добавление точки | Клик ЛКМ на поверхности модели |
| Масштаб | Колесо мыши / клавиши +/- |
| Открыть файл | Ctrl+O |
| Выход | Esc |

### Рабочий процесс:

1. **Загрузка модели**: File → Open OBJ... (выберите .obj файл)
2. **Установка реперных точек**: 
   - Разместите две точки на известных реперных маркерах
   - Введите известное расстояние в метрах в поле "Reference (meters)"
   - Нажмите "Set Scale"
3. **Измерения**:
   - Размещайте точки на поверхности модели (ЛКМ)
   - При включенном "Auto-connect points" точки соединяются автоматически
   - Результаты отображаются в таблице справа
4. **Экспорт**: Нажмите "Export" для сохранения отчёта

## Технические детали

### Поддерживаемый формат OBJ:

- `v x y z` - вершины
- `vn x y z` - нормали
- `f v1/vt1/vn1 v2/vt2/vn2 v3/vt3/vn3` - грани (треугольники)

### Алгоритмы:

- **Moller-Trumbore** - пересечение луча с треугольником для проекции курсора
- **Ray casting** - определение точки на поверхности меша
- **Евклидово расстояние** - расчет расстояний между точками

### Особенности реализации:

- Динамические массивы для хранения вершин и граней
- Bounding box для автоматического позиционирования камеры
- Барицентрическая интерполяция для точного позиционирования на гранях
- OpenGL освещение для лучшей визуализации
